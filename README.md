## Overview

NFS (Node.js File Structure) is a powerful CLI tool that helps you generate well-organized project structures for various frameworks with a single command. Say goodbye to manual folder creation and boilerplate setup!

## Features

- 🚀 Interactive CLI with beautiful interface
- 📦 Multiple framework templates:
  - **Express** (with Prisma or Sequelize ORM)
  - **React** for web applications
  - **React Native** for mobile development
- ⚡ Instant project scaffolding
- 🎨 Clean, production-ready folder structures

## Installation

```sh
$ npm install -g nodejs_file_structure
```

## Usage

Simply run the command below and follow the interactive prompts:

```sh
$ nfs
```

### What to expect:

1. Select your framework (Express, React, or React Native)
2. For Express projects, choose your preferred ORM (Prisma or Sequelize)
